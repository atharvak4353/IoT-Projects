Weather & Air Monitoring

IoT based environmental monitoring system using DHT11, multiple gas sensors, Arduino UNO R4 WiFi and Blynk.

Working Principle

Temperature & Humidity

DHT11 measures temperature and humidity and sends both readings to the Arduino.

Air Monitoring

Three analog sensors are read through A1, A2 and A3. Their analog values are mapped to a 0–100 range.

Wi-Fi Communication

Arduino UNO R4 WiFi connects to the wireless network using the WiFiS3 library.

Blynk Monitoring

Temperature, humidity and gas values are uploaded to Blynk every 2 seconds.

Arduino Code

weather_air_monitoring.ino 
#define BLYNK_PRINT Serial

#define BLYNK_TEMPLATE_ID "YOUR_TEMPLATE_ID"
#define BLYNK_TEMPLATE_NAME "Weather & Air Monitoring"
#define BLYNK_AUTH_TOKEN "YOUR_BLYNK_AUTH_TOKEN"

#include <SPI.h>
#include <WiFiS3.h>
#include <BlynkSimpleWifi.h>
#include <DHT.h>

char ssid[] = "YOUR_WIFI_NAME";
char pass[] = "YOUR_WIFI_PASSWORD";

#define DHTPIN 4
#define DHTTYPE DHT11

DHT dht(
    DHTPIN,
    DHTTYPE
);

const int mq1 = A1;
const int mq2 = A2;
const int mq3 = A3;

BlynkTimer timer;

void sendSensorData()
{
    float co2 =
        analogRead(mq1);

    float ch4 =
        analogRead(mq2);

    float s2 =
        analogRead(mq3);

    co2 = map(
        co2,
        0,
        1023,
        0,
        100
    );

    ch4 = map(
        ch4,
        0,
        1023,
        0,
        100
    );

    s2 = map(
        s2,
        0,
        1023,
        0,
        100
    );

    float temp =
        dht.readTemperature();

    float humidity =
        dht.readHumidity();

    if (
        isnan(temp) ||
        isnan(humidity)
    )
    {
        Serial.println(
            "DHT read failed"
        );

        return;
    }

    Blynk.virtualWrite(
        V0,
        temp
    );

    Blynk.virtualWrite(
        V1,
        humidity
    );

    Blynk.virtualWrite(
        V2,
        co2
    );

    Blynk.virtualWrite(
        V3,
        ch4
    );

    Blynk.virtualWrite(
        V4,
        s2
    );

    Serial.println(
        "Data sent to Blynk"
    );
}

void setup()
{
    Serial.begin(9600);

    pinMode(
        mq1,
        INPUT
    );

    pinMode(
        mq2,
        INPUT
    );

    pinMode(
        mq3,
        INPUT
    );

    dht.begin();

    Blynk.begin(
        BLYNK_AUTH_TOKEN,
        ssid,
        pass
    );

    timer.setInterval(
        2000L,
        sendSensorData
    );
}

void loop()
{
    Blynk.run();
    timer.run();
}
Replace YOUR_TEMPLATE_ID, YOUR_BLYNK_AUTH_TOKEN, YOUR_WIFI_NAME and YOUR_WIFI_PASSWORD before uploading.

Steps to Operate the Project

  1. Connect the DHT11 data pin to digital pin 4.
  2. Connect the three gas sensor analog outputs to A1, A2 and A3.
  3. Connect all VCC and GND connections properly.
  4. Open Arduino IDE.
  5. Select the Arduino UNO R4 WiFi board.
  6. Install all required libraries.
  7. Enter your Wi-Fi and Blynk credentials.
  8. Upload the program.
  9. Open Serial Monitor at 9600 baud.
  10. Open the Blynk dashboard.
  11. Monitor temperature, humidity and air sensor readings.
The Arduino automatically sends updated environmental readings to Blynk every 2 seconds.

Common Problems and Solutions

Problem Possible Cause Solution
Blynk does not connect Incorrect Wi-Fi or Blynk details Check SSID, password and authentication token.
DHT read failed DHT11 wiring problem Check the DHT11 data connection to digital pin 4.
Gas sensor remains at zero Incorrect analog wiring Verify sensors are connected to A1, A2 and A3.
Values not appearing in Blynk Incorrect virtual pins Check Blynk widgets V0 to V4.
