Weather & Air Monitoring

Weather & Air Monitoring Circuit

Working Principle

Temperature & Humidity

DHT11 measures the temperature and humidity of the surrounding environment.

MQ135 Air Quality

MQ135 provides an analog reading used for air quality monitoring.

MQ2 Gas Monitoring

MQ2 provides another analog gas sensor reading to the Arduino.

MQ9 Carbon Monoxide Monitoring

MQ9 provides an analog reading used for carbon monoxide monitoring.

Wi-Fi Communication

Arduino UNO R4 WiFi connects to the wireless network using WiFiS3.

Blynk Monitoring

All sensor values are uploaded to Blynk every 2 seconds.

The system continuously monitors weather and air-quality parameters and sends the readings to Blynk IoT.

Arduino Code

weather_air_monitoring.ino 
#define BLYNK_PRINT Serial

#define BLYNK_TEMPLATE_ID "YOUR_TEMPLATE_ID"
#define BLYNK_TEMPLATE_NAME "Weather & Air Monitoring"
#define BLYNK_AUTH_TOKEN "YOUR_BLYNK_AUTH_TOKEN"

#include <SPI.h>
#include <WiFiS3.h>
#include <BlynkSimpleWifi.h>
#include <DHT.h>

char ssid[] = "YOUR_WIFI_NAME";
char pass[] = "YOUR_WIFI_PASSWORD";

#define DHTPIN 4
#define DHTTYPE DHT11

DHT dht(
    DHTPIN,
    DHTTYPE
);

const int mq1 = A1;
const int mq2 = A2;
const int mq3 = A3;

BlynkTimer timer;


void sendSensorData()
{

    float co2 =
        analogRead(mq1);

    float ch4 =
        analogRead(mq2);

    float s2 =
        analogRead(mq3);


    co2 = map(
        co2,
        0,
        1023,
        0,
        100
    );


    ch4 = map(
        ch4,
        0,
        1023,
        0,
        100
    );


    s2 = map(
        s2,
        0,
        1023,
        0,
        100
    );


    float temp =
        dht.readTemperature();


    float humidity =
        dht.readHumidity();


    if (
        isnan(temp) ||
        isnan(humidity)
    )
    {

        Serial.println(
            "DHT read failed"
        );

        return;

    }


    Blynk.virtualWrite(
        V0,
        temp
    );


    Blynk.virtualWrite(
        V1,
        humidity
    );


    Blynk.virtualWrite(
        V2,
        co2
    );


    Blynk.virtualWrite(
        V3,
        ch4
    );


    Blynk.virtualWrite(
        V4,
        s2
    );


    Serial.println(
        "Data sent to Blynk"
    );

}


void setup()
{

    Serial.begin(9600);


    pinMode(
        mq1,
        INPUT
    );


    pinMode(
        mq2,
        INPUT
    );


    pinMode(
        mq3,
        INPUT
    );


    dht.begin();


    Blynk.begin(
        BLYNK_AUTH_TOKEN,
        ssid,
        pass
    );


    timer.setInterval(
        2000L,
        sendSensorData
    );

}


void loop()
{

    Blynk.run();

    timer.run();

}
Before uploading: replace YOUR_TEMPLATE_ID, YOUR_BLYNK_AUTH_TOKEN, YOUR_WIFI_NAME and YOUR_WIFI_PASSWORD with your own Blynk and Wi-Fi details.

Steps to Operate the Project

  1. Connect the DHT11 sensor according to the circuit diagram.
  2. Connect the MQ135, MQ2 and MQ9 sensors.
  3. Connect all VCC pins to 5V.
  4. Connect all GND pins to GND.
  5. Open Arduino IDE.
  6. Install Arduino UNO R4 Boards .
  7. Install all required libraries.
  8. Complete the Blynk IoT Setup .
  9. Copy your Template ID and Authentication Token from Blynk.
  10. Enter your Wi-Fi name and Wi-Fi password.
  11. Select Arduino UNO R4 WiFi as the board.
  12. Select the correct COM port.
  13. Upload the Arduino program.
  14. Open Serial Monitor at 9600 baud .
  15. Open the Blynk dashboard.
  16. Monitor Temperature, Humidity, MQ135, MQ2 and MQ9 readings.
The Arduino sends updated environmental sensor readings to Blynk every 2 seconds .

Common Problems and Solutions

Problem Possible Cause Solution
Blynk does not connect Incorrect Wi-Fi or Blynk credentials Check Wi-Fi name, password, Template ID and Auth Token.
Blynk Device shows Offline Arduino is not connected to the Internet Verify Wi-Fi connection and credentials.
DHT read failed DHT11 wiring problem Check DHT11 VCC, GND and D4 connections.
MQ readings do not change Incorrect analog connection Check the MQ sensor analog outputs.
Values do not appear on Blynk Incorrect Virtual Pins Verify Datastreams V0 to V4.
Temperature gauge does not update Wrong Blynk Datastream Set Temperature Gauge to V0.
Humidity gauge does not update Wrong Blynk Datastream Set Humidity Gauge to V1.
MQ135 gauge does not update Wrong Blynk Datastream Set MQ135 Gauge to V2.
MQ2 gauge does not update Wrong Blynk Datastream Set MQ2 Gauge to V3.
MQ9 gauge does not update Wrong Blynk Datastream Set MQ9 Gauge to V4.
