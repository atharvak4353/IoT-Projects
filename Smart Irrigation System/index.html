Smart Irrigation System

IoT based automatic irrigation system using Arduino UNO R4 WiFi, soil moisture sensor, rain sensor, DHT11, relay, water pump and Blynk IoT.

The relay used in the program is Active LOW. Therefore: LOW = Pump ON and HIGH = Pump OFF .
Important: Use an appropriate external power supply for the DC water pump. Do not power a high-current pump directly from an Arduino GPIO pin.

Working Principle

Automatic Mode

The Arduino continuously reads the soil moisture level.

If the soil moisture becomes lower than 20%, the relay activates and the water pump turns ON.

When the soil moisture becomes 20% or higher, the water pump turns OFF.

Manual Mode

In Manual Mode, the user can control the water pump directly from Blynk.

Blynk Virtual Pin V4 is used for the Pump Switch.

Virtual Pin V5 is used to select Auto or Manual Mode.

Soil moisture, rain level, temperature and humidity are sent to Blynk every 2 seconds.

Arduino Code

smart_irrigation.ino 
#define BLYNK_TEMPLATE_ID "YOUR_TEMPLATE_ID"
#define BLYNK_TEMPLATE_NAME "Smart Irrigation"
#define BLYNK_AUTH_TOKEN "YOUR_BLYNK_AUTH_TOKEN"

#include <WiFiS3.h>
#include <BlynkSimpleWifi.h>
#include <DHT.h>

char ssid[] = "YOUR_WIFI_NAME";
char pass[] = "YOUR_WIFI_PASSWORD";

#define SOIL_PIN A0
#define RAIN_PIN A1
#define RELAY_PIN 7

#define DHTPIN 2
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

BlynkTimer timer;

#define VPIN_SOIL V0
#define VPIN_TEMP V1
#define VPIN_HUM V2
#define VPIN_RAIN V3
#define VPIN_PUMP V4
#define VPIN_MODE V5

bool autoMode = true;
bool manualPump = false;

void sendSensorData();


BLYNK_WRITE(VPIN_MODE)
{
    autoMode = param.asInt();
}


BLYNK_WRITE(VPIN_PUMP)
{
    manualPump = param.asInt();
}


void sendSensorData()
{

    int soilRaw =
        analogRead(SOIL_PIN);

    int rainRaw =
        analogRead(RAIN_PIN);


    float temperature =
        dht.readTemperature();

    float humidity =
        dht.readHumidity();


    int soilPercent =
        map(
            soilRaw,
            1023,
            0,
            0,
            100
        );


    int rainPercent =
        map(
            rainRaw,
            1023,
            0,
            0,
            100
        );


    Serial.print("Soil: ");

    Serial.print(
        soilPercent
    );


    Serial.print("% Rain: ");

    Serial.print(
        rainPercent
    );


    Serial.print("% Temp: ");

    Serial.print(
        temperature
    );


    Serial.print(" Hum: ");

    Serial.println(
        humidity
    );


    Blynk.virtualWrite(
        VPIN_SOIL,
        soilPercent
    );


    Blynk.virtualWrite(
        VPIN_RAIN,
        rainPercent
    );


    Blynk.virtualWrite(
        VPIN_TEMP,
        temperature
    );


    Blynk.virtualWrite(
        VPIN_HUM,
        humidity
    );


    if (autoMode)
    {

        if (soilPercent < 20)
        {

            digitalWrite(
                RELAY_PIN,
                LOW
            );


            Blynk.virtualWrite(
                VPIN_PUMP,
                1
            );

        }

        else
        {

            digitalWrite(
                RELAY_PIN,
                HIGH
            );


            Blynk.virtualWrite(
                VPIN_PUMP,
                0
            );

        }

    }

    else
    {

        digitalWrite(
            RELAY_PIN,
            manualPump
            ? LOW
            : HIGH
        );

    }

}


void setup()
{

    Serial.begin(9600);


    pinMode(
        RELAY_PIN,
        OUTPUT
    );


    digitalWrite(
        RELAY_PIN,
        HIGH
    );


    dht.begin();


    Blynk.begin(
        BLYNK_AUTH_TOKEN,
        ssid,
        pass
    );


    timer.setInterval(
        2000L,
        sendSensorData
    );

}


void loop()
{

    Blynk.run();

    timer.run();

}
Before uploading: replace YOUR_TEMPLATE_ID, YOUR_BLYNK_AUTH_TOKEN, YOUR_WIFI_NAME and YOUR_WIFI_PASSWORD with your actual Blynk and Wi-Fi details.

Steps to Operate the Project

  1. Connect all components according to the circuit connection table.
  2. Connect the Soil Moisture Sensor output to A0.
  3. Connect the Rain Sensor output to A1.
  4. Connect the DHT11 data pin to D2.
  5. Connect the Relay input to D7.
  6. Connect the water pump through the relay module.
  7. Open Arduino IDE.
  8. Install Arduino UNO R4 Boards .
  9. Install the required libraries.
  10. Complete the Blynk IoT Setup .
  11. Copy your Template ID and Authentication Token.
  12. Enter your Wi-Fi name and password.
  13. Select Arduino UNO R4 WiFi as the board.
  14. Select the correct Arduino COM port.
  15. Upload the program.
  16. Open Serial Monitor at 9600 baud .
  17. Open the Blynk dashboard.
  18. Check Soil Moisture, Rain Level, Temperature and Humidity.
  19. Select Automatic Mode or Manual Mode.
  20. In Manual Mode, use the Pump Control switch to turn the water pump ON or OFF.
The Smart Irrigation System is now ready for operation.

Common Problems and Solutions

Problem Possible Cause Solution
Blynk does not connect Incorrect Wi-Fi or Auth Token Check Wi-Fi name, Wi-Fi password, Template ID and Auth Token.
Device shows Offline Arduino is not connected to Wi-Fi Verify Wi-Fi credentials and Internet connection.
Blynk values do not update Incorrect Virtual Pins Verify V0 to V5 Datastream configuration.
Pump does not start Relay or pump wiring problem Check D7 relay connection, external pump supply and relay contacts.
Pump stays ON Active LOW relay logic Check that LOW means ON and HIGH means OFF in the program.
DHT value is incorrect DHT11 wiring issue Check VCC, GND and D2 connections.
Soil value does not change Soil sensor connection problem Verify that the sensor AO pin is connected to A0.
Rain reading does not change Rain sensor connection problem Verify that the sensor AO pin is connected to A1.
Manual Pump Switch does not work System is in Automatic Mode Select Manual Mode using the V5 Mode Selector.
