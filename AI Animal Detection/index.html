Working Principle

  1. The Raspberry Pi Camera continuously captures live video.
  2. Each camera frame is sent to OpenCV.
  3. The frame is resized and converted into a blob of 300 × 300 pixels for the MobileNet SSD model.
  4. MobileNet SSD analyzes the image and identifies objects.
  5. The program checks whether the detected object is Dog, Cat, Horse, Sheep, Cow or Bird.
  6. Only detections having confidence greater than 0.5 are accepted.
  7. A green bounding box is drawn around the animal.
  8. The animal name is displayed above the bounding box.
  9. The detected animal name is printed in the terminal.
  10. The buzzer turns ON for approximately 0.3 seconds.
  11. Press the Q key to stop the animal detection program.

Raspberry Pi Python Code

animal_detection.py 
import cv2
from picamera2 import Picamera2
import time
from gpiozero import Buzzer

# ---------------- BUZZER SETUP ----------------

buzzer = Buzzer(18)

# ------------------------------------------------

# Load MobileNet SSD model

net = cv2.dnn.readNetFromCaffe(
    "deploy.prototxt",
    "mobilenet_iter_73000.caffemodel"
)

# Animals and birds we want to detect

animal_classes = [
    "dog",
    "cat",
    "horse",
    "sheep",
    "cow",
    "bird"
]

# MobileNet SSD classes

CLASSES = [
    "background",
    "aeroplane",
    "bicycle",
    "bird",
    "boat",
    "bottle",
    "bus",
    "car",
    "cat",
    "chair",
    "cow",
    "diningtable",
    "dog",
    "horse",
    "motorbike",
    "person",
    "pottedplant",
    "sheep",
    "sofa",
    "train",
    "tvmonitor"
]

# Initialize Pi Camera

picam = Picamera2()

picam.configure(
    picam.create_preview_configuration(
        main={"size": (640, 480)}
    )
)

picam.start()

time.sleep(2)

print("Starting Animal Detection... Press 'q' to quit")

# Store previously detected animals
# to avoid repeated terminal messages

last_detected = set()

while True:

    frame = picam.capture_array()

    # Convert BGRA to BGR if required

    if frame.shape[2] == 4:
        frame = cv2.cvtColor(
            frame,
            cv2.COLOR_BGRA2BGR
        )

    # Prepare image for AI detection

    blob = cv2.dnn.blobFromImage(
        frame,
        0.007843,
        (300, 300),
        127.5
    )

    net.setInput(blob)

    detections = net.forward()

    detected_animals = []

    # Detection loop

    for i in range(detections.shape[2]):

        confidence = detections[0, 0, i, 2]

        if confidence > 0.5:

            class_id = int(
                detections[0, 0, i, 1]
            )

            label = CLASSES[class_id]

            if label in animal_classes:

                detected_animals.append(label)

                # Bounding box coordinates

                box = detections[0, 0, i, 3:7] * [
                    frame.shape[1],
                    frame.shape[0],
                    frame.shape[1],
                    frame.shape[0]
                ]

                (x1, y1, x2, y2) = box.astype("int")

                # Draw rectangle

                cv2.rectangle(
                    frame,
                    (x1, y1),
                    (x2, y2),
                    (0, 255, 0),
                    2
                )

                # Display animal label

                cv2.putText(
                    frame,
                    label.upper(),
                    (x1, y1 - 10),
                    cv2.FONT_HERSHEY_SIMPLEX,
                    1,
                    (0, 0, 255),
                    3
                )

    # Buzzer and terminal output

    if detected_animals:

        unique_animals = set(
            detected_animals
        )

        # Print only when a new animal appears

        if unique_animals != last_detected:

            print(
                "Animal Detected:",
                ", ".join(unique_animals)
            )

            last_detected = unique_animals

            # Buzzer alert

            buzzer.on()

            time.sleep(0.3)

            buzzer.off()

    else:

        last_detected = set()

        buzzer.off()

    # Show live camera window

    cv2.imshow(
        "Animal Detection",
        frame
    )

    # Press Q to exit

    if cv2.waitKey(1) & 0xFF == ord("q"):
        break

# Cleanup

buzzer.off()

cv2.destroyAllWindows()

Steps to Operate the Project

  1. Switch OFF the Raspberry Pi before making connections.
  2. Connect the Pi Camera to the Raspberry Pi camera connector.
  3. Connect the positive terminal of the buzzer to GPIO 18.
  4. Connect the negative terminal of the buzzer to GND.
  5. Switch ON the Raspberry Pi.
  6. Install all the required libraries and dependencies.
  7. Download deploy.prototxt and mobilenet_iter_73000.caffemodel.
  8. Keep both MobileNet SSD files in the same folder as the Python program.
  9. Save the Python program as animal_detection.py.
  10. Open the terminal in the project folder.
  11. Run the program using: python3 animal_detection.py
  12. The Pi Camera will start capturing live video.
  13. Place an animal or animal image in front of the camera.
  14. When an animal is detected, a bounding box and animal name will appear on the camera window.
  15. The buzzer will beep when the animal is detected.
  16. Press the Q key to stop the program.
The project successfully identifies supported animals using MobileNet SSD and produces a buzzer alert whenever an animal is detected.

Common Problems and Solutions

Problem Possible Cause Solution
Camera is not opening Pi Camera is not connected correctly Switch OFF the Raspberry Pi and check the camera ribbon cable connection.
No module named picamera2 Picamera2 library is not installed Run: sudo apt install python3-picamera2
OpenCV module not found OpenCV is not installed Run: sudo apt install python3-opencv
deploy.prototxt file not found AI model configuration file is missing Download deploy.prototxt and keep it in the same folder as the Python program.
caffemodel file not found MobileNet SSD model file is missing Download mobilenet_iter_73000.caffemodel and keep it in the project folder.
Animal is not detected Poor lighting, unclear image or low confidence Improve lighting and keep the animal clearly visible in front of the camera.
Buzzer is not working Incorrect GPIO connection Check that the buzzer signal is connected to GPIO 18 and the other terminal to GND.
Detection window does not close Q key was not detected Click on the OpenCV camera window and press the Q key.
