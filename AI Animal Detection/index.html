About the Project

This project implements a real-time AI-based animal detection system using a Raspberry Pi and camera.

The Raspberry Pi continuously captures images from the camera and processes each frame using OpenCV's Deep Neural Network module.

A pretrained MobileNet SSD model analyzes the camera frames and identifies supported animal classes including dogs, cats, horses, sheep, cows and birds.

When a supported animal is detected with more than 50% confidence, the program draws a bounding box around the detected object and displays its class name.

A buzzer connected to GPIO 18 provides an additional physical warning whenever an animal is detected.

Working Principle

1
Camera Capture

Picamera2 continuously captures frames at 640 × 480 resolution.

2
Image Processing

OpenCV receives and prepares each camera frame for AI inference.

3
DNN Input

The image is converted into a 300 × 300 blob for MobileNet SSD.

4
AI Inference

MobileNet SSD analyzes the frame and identifies objects.

5
Animal Filtering

Only the configured animal classes with sufficient confidence are accepted.

6
Detection Output

OpenCV draws a bounding box and displays the animal class.

7
Terminal Output

The detected animal name is printed in the terminal.

8
Buzzer Alert

GPIO 18 activates the buzzer for approximately 0.3 seconds.

9
Continuous Detection

The process repeats continuously until the Q key is pressed.

Python Detection Program

animal_detection.py 
import cv2
from picamera2 import Picamera2
import time
from gpiozero import Buzzer


# ------------------------------------------------
# BUZZER SETUP
# ------------------------------------------------

buzzer = Buzzer(18)


# ------------------------------------------------
# LOAD MOBILENET SSD MODEL
# ------------------------------------------------

net = cv2.dnn.readNetFromCaffe(
    "deploy.prototxt",
    "mobilenet_iter_73000.caffemodel"
)


# ------------------------------------------------
# ANIMALS TO DETECT
# ------------------------------------------------

animal_classes = [
    "dog",
    "cat",
    "horse",
    "sheep",
    "cow",
    "bird"
]


# ------------------------------------------------
# MOBILENET SSD CLASSES
# ------------------------------------------------

CLASSES = [
    "background",
    "aeroplane",
    "bicycle",
    "bird",
    "boat",
    "bottle",
    "bus",
    "car",
    "cat",
    "chair",
    "cow",
    "diningtable",
    "dog",
    "horse",
    "motorbike",
    "person",
    "pottedplant",
    "sheep",
    "sofa",
    "train",
    "tvmonitor"
]


# ------------------------------------------------
# INITIALIZE PI CAMERA
# ------------------------------------------------

picam = Picamera2()

picam.configure(
    picam.create_preview_configuration(
        main={
            "size": (640, 480)
        }
    )
)

picam.start()

time.sleep(2)

print(
    "Starting Animal Detection... "
    "Press 'q' to quit"
)


# Store previous detections to avoid
# repeatedly printing the same animal

last_detected = set()


# ------------------------------------------------
# MAIN DETECTION LOOP
# ------------------------------------------------

while True:

    frame = picam.capture_array()


    # Convert BGRA to BGR if required

    if frame.shape[2] == 4:

        frame = cv2.cvtColor(
            frame,
            cv2.COLOR_BGRA2BGR
        )


    # Prepare frame for MobileNet SSD

    blob = cv2.dnn.blobFromImage(
        frame,
        0.007843,
        (300, 300),
        127.5
    )


    net.setInput(blob)

    detections = net.forward()

    detected_animals = []


    # ------------------------------------------------
    # PROCESS DETECTIONS
    # ------------------------------------------------

    for i in range(
        detections.shape[2]
    ):

        confidence = detections[
            0,
            0,
            i,
            2
        ]


        if confidence > 0.5:

            class_id = int(
                detections[
                    0,
                    0,
                    i,
                    1
                ]
            )


            label = CLASSES[
                class_id
            ]


            if label in animal_classes:

                detected_animals.append(
                    label
                )


                # Bounding box coordinates

                box = detections[
                    0,
                    0,
                    i,
                    3:7
                ] * [
                    frame.shape[1],
                    frame.shape[0],
                    frame.shape[1],
                    frame.shape[0]
                ]


                (
                    x1,
                    y1,
                    x2,
                    y2
                ) = box.astype("int")


                # Draw bounding box

                cv2.rectangle(
                    frame,
                    (x1, y1),
                    (x2, y2),
                    (0, 255, 0),
                    2
                )


                # Display animal label

                cv2.putText(
                    frame,
                    label.upper(),
                    (x1, y1 - 10),
                    cv2.FONT_HERSHEY_SIMPLEX,
                    1,
                    (0, 0, 255),
                    3
                )


    # ------------------------------------------------
    # BUZZER AND TERMINAL OUTPUT
    # ------------------------------------------------

    if detected_animals:

        unique_animals = set(
            detected_animals
        )


        if unique_animals != last_detected:

            print(
                "Animal Detected:",
                ", ".join(
                    unique_animals
                )
            )


            last_detected = unique_animals


            buzzer.on()

            time.sleep(0.3)

            buzzer.off()


    else:

        last_detected = set()

        buzzer.off()


    # ------------------------------------------------
    # DISPLAY CAMERA WINDOW
    # ------------------------------------------------

    cv2.imshow(
        "Animal Detection",
        frame
    )


    # Press Q to exit

    if (
        cv2.waitKey(1)
        & 0xFF
        == ord("q")
    ):

        break


# ------------------------------------------------
# CLEANUP
# ------------------------------------------------

buzzer.off()

cv2.destroyAllWindows()

How to Run the Project

  1. Switch OFF the Raspberry Pi.
  2. Connect the Pi Camera to the Raspberry Pi camera connector.
  3. Connect the buzzer positive terminal to GPIO 18.
  4. Connect the buzzer negative terminal to GND.
  5. Switch ON the Raspberry Pi.
  6. Install the required libraries and dependencies.
  7. Download deploy.prototxt.
  8. Download mobilenet_iter_73000.caffemodel.
  9. Keep both MobileNet files in the same directory as the Python program.
  10. Save the program as animal_detection.py.
  11. Open a terminal in the project directory.
  12. Run: python3 animal_detection.py
  13. The camera starts capturing live video.
  14. Place an animal or suitable animal image in front of the camera.
  15. The detected animal receives a bounding box and class label.
  16. The buzzer produces an alert.
  17. Press Q to stop the program.

Troubleshooting

Problem Possible Cause Solution
Camera not opening Camera connection issue Power OFF the Pi and verify the ribbon cable.
No module named picamera2 Picamera2 is missing Install python3-picamera2.
OpenCV module not found OpenCV is not installed Install python3-opencv.
deploy.prototxt not found Model configuration is missing Keep deploy.prototxt in the project folder.
caffemodel not found AI model file is missing Keep mobilenet_iter_73000.caffemodel in the project folder.
Animal not detected Poor lighting or low confidence Improve lighting and ensure the animal is clearly visible.
Buzzer not working Incorrect GPIO wiring Verify GPIO 18 and GND connections.
Q does not close the window OpenCV window is not active Click the camera window and press Q.
